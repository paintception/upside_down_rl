Upside-Down Reinforcement Learning

Exploring tree-based methods for interpretable policies in UDRL

View on GitHub Download Paper

Abstract

Model-Free Reinforcement Learning (RL) algorithms either learn how to map states to expected rewards, or search for policies that can maximize a certain performance function. Upside-Down Reinforcement Learning (UDRL) is a novel learning paradigm that aims to learn how to predict actions from states and desired commands. We investigate whether tree-based methods like Random Forests and Extremely Randomized Trees can be used within a UDRL framework, providing interpretable policies.
